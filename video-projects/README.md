# Video project sources

Editorial project files live beside the website they explain. Reusable rendering code lives in [ampytech-video-gen-tools](https://github.com/arvindpereira/ampytech-video-gen-tools).

- [Prop 37 sketchbook pilot](ca-2026/prop-37/README.md): scene graph, script, captions, research, illustration prompts and validation.
- Generated art, narration and rendered videos are stored outside Git. Each scene graph references hashed media in an external asset store.
- Commit project JSON and text changes here. Render locally with the tooling repository. Use its asset-bundle command to back up or transfer media independently.
