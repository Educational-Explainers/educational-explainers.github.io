# Video project sources

Editorial project files live beside the website they explain. Reusable rendering and recording code lives in [ampytech-video-gen-tools](https://github.com/arvindpereira/ampytech-video-gen-tools).

- [California 2026 full series](ca-2026/README.md): 14 sketchbook videos, scene graphs, scripts, timed teleprompters and a portable Mac recording pack.
- Generated art, narration and rendered videos stay outside Git. Scene graphs reference hashed media in an external asset store.
- Commit project JSON and text changes here. Render and export locally with the tooling repository. Back up or transfer media independently using its asset-bundle tools.
