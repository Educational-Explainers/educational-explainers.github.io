# educational-explainers.github.io
Website for explainer webpages I create to help understand and explain complex topics that affect the community locally, state-wide, nation-wide or globally. I'm mostly creating these to help educate people and my goal is to NOT be political - I want everyone to make informed decisions through providing factual arguments for/against.

The ballot guide and supporting research page use Google Analytics 4 (`G-74MZ9ES5M0`). When adding a public HTML page, include the same Google tag once in its `<head>`. View traffic in the corresponding Google Analytics property; Realtime is useful for checking new visits.
